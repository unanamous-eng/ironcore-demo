A production-ready, luxury single-page fitness website built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and PostgreSQL via Drizzle ORM.

## 📋 Setup Instructions

### Prerequisites

- Node.js 18+
- PostgreSQL database

### 1. Clone & Install

```bash
git clone <repo-url>
cd apex-elite-delhi
npm install
```

### 2. Environment Variables

Create a `.env` file:

```env
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
ADMIN_EMAIL=admin@apexelite.demo
ADMIN_PASSWORD=Demo@Elite49
JWT_SECRET=your-super-secret-key-here
```

### 3. Push Database Schema

```bash
npx drizzle-kit push
```

### 4. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### 5. Build for Production

```bash
npm run build
npm start
```

## 🚀 Vercel Deployment

> **IMPORTANT**: You need a PostgreSQL database accessible from the internet.
> Vercel does NOT provide a local DB — you must use an external provider.

### Option A: Vercel Postgres (easiest)

1. Push code to GitHub
2. Import project in [Vercel](https://vercel.com)
3. Go to **Storage** tab → **Create Database** → **Postgres**
4. Connect the database to your project (this auto-sets `DATABASE_URL`)
5. Go to **Settings → Environment Variables** and add:
   - `ADMIN_EMAIL` = `admin@apexelite.demo`
   - `ADMIN_PASSWORD` = `Demo@Elite49`
   - `JWT_SECRET` = any long random string (e.g. `mysecret123xyz`)
6. **Redeploy** after adding env vars
7. After first deploy, open your Vercel Postgres console and run the schema:
   - Or locally: `DATABASE_URL="your-vercel-postgres-url" npx drizzle-kit push`

### Option B: External DB (Neon, Supabase, Railway, etc.)

1. Create a free PostgreSQL database at [Neon](https://neon.tech) or [Supabase](https://supabase.com)
2. Push code to GitHub
3. Import project in [Vercel](https://vercel.com)
4. Go to **Settings → Environment Variables** and add:
   - `DATABASE_URL` = your Neon/Supabase connection string
   - `ADMIN_EMAIL` = `admin@apexelite.demo`
   - `ADMIN_PASSWORD` = `Demo@Elite49`
   - `JWT_SECRET` = any long random string
5. Deploy!
6. Run schema migration: `DATABASE_URL="your-db-url" npx drizzle-kit push`

### ⚠️ Common Deployment Errors

| Error | Fix |
|-------|-----|
| `DATABASE_URL is required` | Add DATABASE_URL to Vercel Environment Variables |
| `Failed to collect page data` | Redeploy after adding env vars |
| Forms return 500 errors | Run `npx drizzle-kit push` against your production DB |
